# MySQL 管理器

在 MySSH 中浏览 MySQL 数据、理解表结构与逻辑关系，并分享可交互的结构文档。

## 数据浏览与查询

- 保存和切换多个连接；支持手动地址与可选 Kubernetes 服务来源。
- 数据库与表的树形导航、名称筛选、可拖动侧栏、多表标签页。
- 打开表默认查看内容；结构页展示字段类型、键、默认值、表与字段 COMMENT。
- 执行 SQL、查看历史与查询结果，支持排序、分页和 CSV 导出。
- 表内容支持新增、修改、删除；枚举单元格提供下拉选择与明确的保存、取消操作。

## 复杂字段

JSON 单元格以简短摘要显示，点击打开只读详情；支持树形与原文、键值搜索、复制和全屏。对象与数组可以逐层折叠，较大列表按需展开。二进制字段中的有效 UTF-8 文本直接显示，其他字节以十六进制展示。

数据库声明的 `ENUM` 显示为低饱和标签，表头可查看全部选项与中文注释。编辑时区分 SQL NULL、空字符串和文本 `NULL`，并使用完整主键定位行；没有主键或不能安全识别主键时拒绝保存。普通文本字段和自由 SQL 结果不会根据采样值推断枚举；新增行仍使用原输入方式。

## COMMENT 逻辑关系

通过 SQL 注释维护关联，无需创建物理外键：

| 声明 | 写入位置 | 含义 |
| --- | --- | --- |
| `@ref(users.id)` | 字段 COMMENT | 单字段引用 |
| `@relation((tenant_id,user_id)->users(tenant_id,id))` | 表 COMMENT | 多字段按顺序配对 |
| `@mapping(audit_events)` | 表 COMMENT | 仅表级业务映射，不提供 JOIN |

点击数据库下的「逻辑关系」读取当前账号可见的元数据。中文说明与机器声明分开显示，完整原始 COMMENT 可展开查看。支持搜索、类型筛选、关联组、自动分层布局、连线选择和字段详情。

画布支持拖动、触控板滚动平移、Ctrl/Cmd+滚轮及触控板捏合缩放、适应全图与定位所选。DOM 文字与 SVG 连线随倍率重绘，输入按帧合并，布局与路径计算不随平移缩放重复执行。密集组合关系默认显示一条主线，选择后显示字段分支。

有效字段关系可以生成带完整配对条件的 `LEFT JOIN` 草稿，默认 `LIMIT 100`，由用户审阅执行。目标缺失或不可见时禁用生成，类型差异有提示；业务映射始终禁止 JOIN。不推断关系基数，不校验业务数据完整性，不自动创建或修改约束。

完整语法与边界见 [COMMENT 逻辑关系说明](../../docs/mysql-logical-relations.md)。

## 导出交互式 HTML

「导出 HTML」保存当前关联组、类型和搜索范围的快照，包含相关表的字段类型、键、注释、关系详情与有效的只读 JOIN 草稿。查看器支持搜索、筛选、平移缩放与字段说明，不依赖 MySSH 或数据库连接。

单文件内嵌样式、脚本和数据，不引用外部字体、图片或 CDN；不包含业务数据行、连接配置或凭据。导出的结构名称与 COMMENT 会随文件分享，请按文档内容选择接收范围。文件不会自动随数据库更新；每次最多 100 条声明、最大 2 MiB，超过时需要缩小范围。离线筛选保留原空间位置，不重新布局。

当前采集端支持 MySQL COMMENT 协议；这不表示已经支持其他数据库的元数据采集。

## 安装与连接

在 MySSH「设置 → 插件市场」安装并启用 MySQL 管理器 `1.4.0`。桌面需要 MySSH `1.3.0+`；Kubernetes 来源需要具有相应能力的新版宿主，终端入口需要 MySSH `1.5.0+`。

新建连接填写 MySQL 地址和账号。默认由宿主按需管理本机 Companion Runtime，分配临时端口与 token，无需手动启动代理。自定义代理地址优先；远程代理应使用 WSS、访问 token 和精确来源限制。账号仍受数据库自身权限约束。

Kubernetes 来源先在宿主面板导入配置并发现服务；连接时建立本机回环通道，断开或失败时清理。插件不直接启动 kubectl；Redis/PostgreSQL 可通过宿主建立通道，但本插件不提供其数据浏览器。Kubernetes 连接密码仅在本次运行内存中保留；手动地址连接沿用既有本地存储方式。

## 终端入口

终端界面由 MySSH Core 直接连接数据库，提供加密连接配置、库表与结构浏览、索引与建表 SQL、分页排序、行操作、SQL 编辑与历史、CSV 导出。终端与桌面连接存储独立，不自动迁移。桌面关系画布、JSON 详情和交互式 HTML 导出仅在桌面工作区提供。
