# 功能截图

`mysql-workspace.png`、`mysql-json.png`、`mysql-enum.png`、`mysql-relations.png` 使用 MySQL 管理器 1.4.0 的真实 React 组件与样式，在浏览器中交互后截图。

截图中的 `demo_store`、`users`、`orders`、`order_items`、`products`、演示用户与 JSON 内容均为虚构夹具；查询由内存适配器提供，未连接真实数据库。顶部明确标示「功能演示 · 全部为虚构数据」。这些图片展示插件工作区，不冒充完整桌面宿主截图。

已核对内容浏览、JSON 展开、ENUM 选项与中文说明、关系选择及适应全图。截图未使用真实凭据、电话、邮箱、外部服务器、业务表结构或数据。图像只做无损压缩，不对界面内容修图。
